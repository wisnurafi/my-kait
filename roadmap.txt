Data & storage rules
- Neon Postgres (Drizzle): all persistent state. Schema changes must be pushed
  to production BEFORE the PR that introduced them is merged.
- Webhook URLs: encrypted at rest (AES via WEBHOOK_ENCRYPTION_KEY, versioned).
- API keys: mk_live_... shown once; only SHA-256 hash stored.
- Share links: unguessable slugs; revokable from the template page.

Notes
- One branch per feature, Vercel preview before merge; maintainer merges himself.
- pnpm tsc --noEmit is the verification gate (must pass before pushing).
- "use server" files may only export async functions (Next build rule).
- Server actions declare explicit return types for "error" in res narrowing.
- Bilingual: leftover untranslated strings after a locale switch are a major bug —
  audit-and-fix everything, not just the touched spot.
- Copy voice: first-person indie-dev, concrete and honest; no generic AI phrasing.
- Production refuses to boot without Upstash credentials and CRON_SECRET —
  never bypass those guards.
- Background jobs log an info-level heartbeat (a quiet job must not look dead).
